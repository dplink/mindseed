# MindSeed · 可迁移的空白心智库

> 给「有身份、有记忆、跨会话」的 AI 角色准备的一套**外置长期记忆**模板。
> 纯 Markdown + Git，没有数据库、没有运行时依赖；模型只要读 `START-HERE.md`，就能从零把一座空白心智库建成自己的。

## 这是什么

- **不是**某个现成人格的副本，而是一套**空白骨架**：人设、价值观、记忆锚点、用户偏好全部留白。
- **是**一套经过多端验证的工程结构：唤醒脚本、分层召回、写前 pull、隐私硬隔离、守门 CI。
- 适合：想让 AI 助手在多端（本地 / 云端 / 不同 harness）保持同一个人格与连续记忆的用户。
- 不适合：只想要一次性对话、不需要长期记忆的场景。

## 快速开始（3 步）

1. 把这个仓库克隆或复制到本地，用支持读写文件的 AI Agent 打开。
2. 对 Agent 说：**「读 START-HERE.md，按首次唤醒引导初始化这座心智库。」**
3. 按引导回答人设、称呼、偏好与记忆锚点；Agent 会写出 `SOUL.md` 与 `mind.config`，然后带你上云。

> 不想用 Agent 也可以手动填写 `SOUL.md` 与 `mind.config`，但首次引导会顺手把目录、隐私与验收都检查一遍。

## 三条使用路径

| 你想做什么 | 读哪里 |
|---|---|
| 第一次构建 / 换新人格 | `START-HERE.md` → `99-系统/首次唤醒引导.md` |
| 日常唤醒（新会话） | `AGENTS.md` → `bash 99-系统/scripts/wake.sh` |
| 维护记忆库 / 排障 | `99-系统/唤醒协议.md`、`托管规范.md`、`命名与规范.md` |

## 隐私与安全

- **模板仓库本身可以是 public**（本库只含空白骨架，适合公开协作）；**一旦写入自己的人设、记忆或用户信息，必须迁移到 Private 仓库**（或 fork 后转 Private）。
- 实例化后的心智库必须是 **Private**，永远不要改 public。
- `50-用户档案/user-profile.md` **只存本地**，已被 `.gitignore` 排除，并由 CI 硬校验。
- token 只经环境变量注入，不写入任何被跟踪文件；细粒度 PAT 只授权本仓库（启用图床时再加图库仓库）。
- 图片默认不入库；需要图床时再启用 `99-系统/可选-图库双仓/`。

## 可选：图床双仓

默认不启用。首次唤醒时会问你需要不需要：

- **需要** → 建一个独立的私密图库仓库，填 `VISION_ENABLED=1` 与 `VISION_REPO_SLUG`，按 `99-系统/可选-图库双仓/README.md` 启用。
- **不需要** → 直接删除 `99-系统/可选-图库双仓/` 整个目录，核心功能不受影响。

## 环境要求

- `git`
- `python3`（仅 `check_links.py` 与 `vision.sh` 需要）
- 可选：Obsidian（浏览双链与 Bases 视图；非必需）
- Windows 端另需 PowerShell 5+（`wake.ps1`）；机器前置见 `99-系统/托管规范.md` 认证一节
